# Instruções para agentes

- Não edite, reformate, renomeie ou exclua arquivos Markdown (`*.md`), incluindo `readme.md` e este `AGENTS.md`, a menos que o usuário peça explicitamente uma alteração em Markdown.
- Esta regra vale mesmo quando a edição parecer útil para documentar uma mudança de código. Faça alterações na documentação somente com autorização explícita do usuário.
